# SPR 两阶段增量实验记录（2026-11-05）

## 范围

四案均为独立 gem5-spr FS、C4，配置每核 50 万条指令预热；测量在首个
参与核达到 1,000 万条 user UOP 时共同结束，不表示每核均执行了 1,000 万条。
采集与维护工具的 source、目标身份、退休和 task PMU
审核已完成；FST 功能字段由 OoO 采集器获得，不含采样 OoO 时间或命中作为
模型输入，但独立 Atomic/QEMU 生产者端到端等价尚未证明。用户允许非严格
匹配的计时起点，因此以下 CPI 是同退休人口的参考对照，不是严格同起点结果。
各案 OFF/ON 是同一二进制配对；不同案的二进制版本不完全相同。全部数字为
任务活跃周期 / 任务退休宏指令，绝对误差单位为 cycles/macro。
