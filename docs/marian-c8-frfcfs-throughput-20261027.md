# Marian C8 / 32GiB FR-FCFS候选吞吐对照（2026-10-27）

同一10M共同终点FST，固定放置、串行交错各3次：候选测量阶段吞吐P50相对旧模式 **-6.25%**，测量墙钟 **+6.67%**；含warmup的内部模拟墙钟 **+6.91%**，含输入校验/准备的完整进程墙钟 **+2.42%**。这是单案共享宿主观测，不是全负载默认推广或独占宿主吞吐验收。

## 数据、配置与测量

- 唯一来源：`c08-872.marian_s`，8核、32GiB双段DDR4，最快核10M measured user UOP共同终点；实际测量user UOP **72,960,546**，混合user+kernel UOP **73,174,407**，warmup UOP **18,293,365**。
- 旧模式为原冻结配置；候选仅关闭`dram.frfcfs_topology_scaled_window`、设`dram.frfcfs_selection_window=64`并开启`dram.frfcfs_causal_selection`。store prepare等其他候选保持关闭。
- 二进制SHA256：`911ac2738d3b58fd8e48c9a594ab45701d959ec41d26b7a37cdc4f62d4cdb973`；两侧完全相同。已有源资格之外，再对本轮首个旧/新输出调用冻结维护入口`--source-root --stats-dir`重新审核，两侧均预期1案、发现1案、通过1案。其余重复输出的输入身份、逐核周期、task PMU及active/elapsed均与各自已审核输出完全一致。
- 顺序：旧—新—新—旧—旧—新；每次fresh process，严格一次一个FastSim。保留已有热文件页缓存，不drop cache；不把目标功能warmup当作宿主页缓存预热。
- 固定`numactl --physcpubind=48-56 --membind=1`，9个同socket物理CPU容纳8个domain workers及主线程。governor/driver、NUMA balancing、每2秒load/CPU/并发进程采样记录在实验目录。
- 主机192逻辑CPU，共享、无独占CPU预留；运行load1范围 **2.45–5.30**，采样中FastSim并发最大1。预检查CPU56曾有约60%的一秒短时占用，因此不宣称完全安静或受隔离宿主。该原始样本保留，未据此删掉某一结果。
