# SPR 受限双层预取四案对照（2026-11-06）

四案均为同一批 gem5-spr C4 retired-stream 输入，使用同一个 FastSim 二进制、同一 joint 配置和 112–119 绑核，逐案串行开启/关闭预取。二进制及运行命令、配置、原始结果和计时见 `tmp/spr-resident-four-repaired-20261106/`；四案目标身份检查均通过。输入来自 gem5 FS 采集，独立 Atomic/QEMU 生产者等价性尚未证明；CPI 的起点仍不是严格对齐。

开启组 L1 只从本核 L2 预取，L2 只从 LLC 预取，不为预取发起 DRAM 请求。普通请求仍使用 buffer TSO 与 FR-FCFS。开启组绕过 private preview，故性能变化同时包含该路径变化；墙钟是共享机器上的单次样本，不代表稳定吞吐。
