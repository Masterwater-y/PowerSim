## 身份、配置和复现边界

- 安装 M5 ELF：`b869c0041b7ca6cf625e8aebdd6392e7c4a52be95ad1466052dc3d39e7d5f1b8`。当前入口为 `configs/spr-evaluation-default.cfg`，选中 `configs/spr-m5-private-preview-clocks.cfg`；Estimated 时序路径保持关闭。逐案例配置、FST 路径、manifest 与参考审计哈希列于 [prepared-roster.json](../tmp/private-clock-retained-c4-c8-c16-20261117/prepared-roster.json)。
- C4 使用 CPU 52–55，C8 使用 CPU 52–59，C16 使用 CPU 48–63；这些是不同物理核心。C4/C8 的启动频率快照为 3.8 GHz，不代表全程频率。C16 的 sysfs 全程采样范围均约为 3.1–3.8 GHz，各例采样均值约 3.64–3.66 GHz；这些是采样值，不是按忙碌周期加权的有效频率。
- 测量阶段速率的分子为测量窗口实际 user UOP，分母为模拟测量阶段墙钟；预加载成功并保留在日志中。全进程速率的分母另含启动器检查、读取/解压、预加载校验、初始化、功能 warmup、结果输出与进程退出。两者不是同一个吞吐口径，也不通过扣除线程 CPU 时间计算。
- 本轮关闭了回放内 FST 内容身份哈希。快速 CPI 验证使用含原始身份记录的归档 stats，检查来源路径/大小及人口，再以本轮完整 time_accounting 一致性关联结果；不能据此声称本轮 FST 内容哈希已核验。PMU 参考来自保存的独立 native retired-cache 审计，不使用 kernel-events 的 path-class 缓存字段。目标身份与硬件事件等价未重新严格认证。
- native unknown 在 XZ C4、zstd C8、XZ C16 分别为每事件 1、2、1，其余为 0；不清零。按此前许可，对这三例以已知计数报告暂定误差；未知成员全部为 miss 时，原批次最大敏感性为 0.010243 个百分点。模型自身的 unknown 和 native unknown 是不同字段，完整计数与 exact/estimated 组成保留于 [结果 JSON](../tmp/m5-remeasure-20261118-16host/results.json)。
- 旧 C16 回放使用 12 个宿主核心，仅作历史对照；本表 C16 为 16 个宿主物理核心的新回放。此前 C8 Graph500 中断及日志已保留，完成案例经过哈希核对后恢复，不把中断样本计入结果。
