# SPR FU Gap Reservation Implementation Plan

> **For agentic workers:** use `superpowers:executing-plans` and follow the checked tasks below.

**Goal:** Avoid a later SPR port reservation falsely blocking an earlier independent UOP while retaining the existing two-stage model.

**Architecture:** Keep the existing interval scheduler and response feedback. Add an opt-in sorted half-open reservation calendar per physical port and, only for multi-cycle issue intervals, per port/op-class. Discard reservations before the monotone dispatch lower bound. Preserve the previous scalar path and port selection policy.

**Tech Stack:** C++17, existing FastSim configuration, C++ tests and full-FLAC replay.

**Spec:** [FLAC C4 diagnosis](../../spr-flac-c4-cpi-diagnosis-20261105.md#spr-共享-fu-未来预约错误局部修复方案)
