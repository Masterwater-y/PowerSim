documentation and validation work belongs on this branch.

curated documentation and SPR gitlinks from local snapshot

only. No speculative/wrong-path streams or shadow traffic are required or
generated by the new frontend. Native fetch/delivery/rename timestamps and

documented limitations. Frontend implementation and acceptance results are
recorded in later commits on `fastsim-spr`.
